# Documents

Formatting reference version: **1**

Identify the target format: Markdown, a word processor, HTML, or a PDF produced
from an editable source. Follow the document's established structure. Voice
governs prose; document structure governs headings, lists, tables, captions,
and references.

Use native heading styles and lists in word processors. Use Markdown syntax
only when the target interprets it. For HTML, use semantic elements; for PDF,
edit the source and render again when available. Keep technical tokens and
quoted passages intact. Choose tables for genuine tabular relationships, not
as a substitute for paragraphs.

For a formatting-only request, preserve wording, heading text, list order, links,
and references. Inspect the resulting document for broken numbering, headings,
tables, and page flow. Editing a local file does not authorize uploading it or
changing sharing permissions.
