# Text messages

Formatting reference version: **1**

Use plain text and intentional line breaks. Preserve literal punctuation and
identifiers; do not add HTML tags, Markdown emphasis, or code fences. Keep links
as readable URLs when needed. Length, greetings, emoji, and closings come from
the applicable profile and audience, not a universal texting persona.

Deliver one message unless the user asks for multiple messages. Carrier SMS
segmentation and app message bubbles are different; do not turn a long message
into several sends automatically. Check the actual tool's length and encoding
limits rather than assuming all text transports behave like SMS.

An already sent text may not support editing. If the user asks to fix its
formatting and editing is unavailable, provide the corrected text and explain
the limitation. Do not send a follow-up without authorization.
