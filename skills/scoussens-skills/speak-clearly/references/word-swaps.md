# Word swaps

Substitutions from the
[Google word list](https://developers.google.com/style/word-list), which remains
the authority. Listed here are the entries that come up most in developer prose.

## Filler and false ease

| Instead of | Write |
| --- | --- |
| simply, just, easy, easily | omit — state the steps |
| quickly | omit, or give the actual duration |
| powerful, robust, seamless, blazing | the specific capability or measurement |
| please | omit, except when requesting a genuine favour |
| note that, it's important to note that | omit — the sentence is already there |
| and so on, etc. | name the remaining cases, or omit |
| actionable | that you can act on |

## Plain words

| Instead of | Write |
| --- | --- |
| utilize | use |
| leverage | use, build on |
| commence | start |
| in order to | to |
| via | through, by way of |
| a number of | some, many, or the number |
| makes use of | uses |
| e.g. | for example, such as |
| i.e. | that is |
| aka | also known as |
| and/or | pick *and* or *or*, or write both cases |
| allows you to | lets you |

## Precise verbs

| Instead of | Write |
| --- | --- |
| access (verb) | see, edit, find, use, view |
| abort | stop, cancel, exit, end |
| kill | stop, exit, end |
| execute | run |

## Inclusive language

| Instead of | Write |
| --- | --- |
| whitelist | allowlist |
| blacklist | denylist, blocklist |
| graylist | provisional list |
| master / slave | primary / replica, controller / worker |
| sanity check | validation check, confidence check |
| dummy value | placeholder value |
| native (feature) | built-in |
| he, she (generic) | they |

Ableist and figurative phrasing — *crazy*, *insane*, *blind to*, *cripples*,
*dumb* — has a literal replacement in nearly every case: *unexpected*,
*unaware of*, *slows*, *inactive*.
